Limits

Everything runs in your browser. JS runs in a Web Worker (10 s limit, no DOM). Python is Pyodide (WebAssembly; first run downloads ~10 MB). The terminal is NOT a Linux shell. Uploads are text-only and never auto-executed. Data stays in this browser's IndexedDB.
